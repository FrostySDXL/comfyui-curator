      Operator Help

      Contextual cues

      A small hint appears near the workspace as you move between review contexts. Dismiss a hint when you know it; reopen this Help dialog any time.

      • Browse: click an image to open; choose Select or hold Ctrl/Cmd+click to select.
      • Selection: Ctrl/Cmd+A select all, Shift+click adds a range, and Esc clears.
      • Lightbox: Left / Right navigate, S/F/R move, Shift+F favorites, and M opens metadata.
      • Compare: Alt+Left/Right advance the pair, C pins A, and Left/Right changes B.

      Global shortcuts

      • / open batch sidebar if closed, then focus batch search
      • Ctrl/Cmd+K open batch sidebar if closed, then focus and select batch search
      • P open Library Search on the last-used Images or Prompt groups tab (the dialog initially focuses Close)
      • Ctrl/Cmd+A select all images in current folder (not in lightbox)
      • Ctrl/Cmd+Z undo last move while undo is available
      • Undo / History keeps the newest eligible manual review move available across reloads for 30 days (up to 100); it excludes deletion, import, AI moves, and public exports.
      • U toggle the batch sidebar
      • F toggle favorites-only filter
      • B toggle AI badges when an AI run is available
      • H toggle muted GIF/video hover previews
      • V toggle score sort when an AI run is available
      • I toggle AI sidebar
      • Esc exit selection, close lightbox or Help, or clear batch search (context-dependent)

      Lightbox shortcuts

      • Left / Right previous or next image
      • [ / ] previous or next scored image
      • Space play or pause the active lightbox video
      • M toggle PNG generation metadata when available
      • I toggle the lightbox AI review panel
      • P prepare a public copy for the current image
      • S / F / R move to shortlisted, finals, or rejects
      • Shift+F toggle favorite for the current image
      • + / - / 0 zoom in, zoom out, reset zoom
      • Ctrl+wheel zoom in/out around the cursor
      • Drag zoomed images to pan around details
      • Compare in Lightbox is available when exactly two review-folder images are selected.
      • Click a compare pane to make it active; move, favorite, public, metadata, and AI actions apply to that pane.
      • C pins the active compare image as A, or clears Pin A; Left/Right walk the candidate B.
      • Alt+Left/Right advances both compare panes together. Sync Pan/Zoom and A/B Split are available in the compare controls.

      Review workflow

      • Browse opens images on ordinary click; Select toggles them.
      • Ctrl/Cmd+click selects disjoint images; Shift+click adds a range. Shift takes precedence when both are held.
      • View contains density, favorites-only, and available AI display filters.
      • Inbox holds new images for review.
      • Move keepers to Shortlisted or Finals; move rejects to Rejects.
      • Use favorites, Prompt History, and metadata as review aids. The lightbox detects adjacent asset.ext.json or asset.json sidecars and structures recognized external-favorites fields and tags.
      • Public posting creates generated derivatives; originals stay in review folders.
      • AI scores are advisory evidence. Manual moves remain authoritative.

      AI Curate

      • Inspect shows selected-image AI details, or a multi-select summary with expandable image rows.
      • Score guides checklist, scope/model, and outcome setup before submission. Up to 12 total element and quality checks are scored.
      • Runs shows saved batch runs and can compare one run against another run from the same batch.
      • AI badges, score sorting, and filters are batch-scoped and reset when no active run is available.
      • Manual moves remain authoritative; AI scores are advisory evidence only.

      Public Posting

      • Prepare Public Copies creates metadata-stripped generated derivatives in the batch public folder.
      • Original review images are never modified by public posting actions.
      • Public shows one batch's generated copies; All Public aggregates generated copies across batches.
      • Copy, move, and delete actions in public views affect generated public copies only.
      • External copy or move requires IMAGE_CURATOR_PUBLIC_EXPORTS.

      Library Search

      • P opens Library Search on the last-used Images or Prompt groups tab.
      • Images searches filenames, PNG generation metadata, and bounded adjacent JSON keys and values across the current folder, batch, or all batches.
      • Filter Workspace sends the current Images query into the review grid. Large result sets load automatically as you scroll or navigate, and Lightbox Previous/Next stays inside the full result set until you edit or clear the filter.
      • Media search indexes are rebuildable snapshots; the files and their sidecars remain authoritative. Rebuild after editing sidecar contents in place.
      • Prompt groups preserves the specialized Prompt History view for normalized positive/negative prompt pairs.
      • Build Index scans PNG metadata for the selected batch. Build All Indexes asks for confirmation.
      • Stale badge means the cached image count changed; click Rebuild Index.
      • Search prompts, negative prompts, and batch labels; refine the search to narrow large result sets.
      • Select a prompt row, then use the rail to show its full positive prompt, negative prompt, or image names.
      • Selected-prompt view options stay active as you select other rows; image references remain display-only.
      • Use copy positive, copy negative, and copy pair to reuse prompts.
